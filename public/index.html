Connection setup (once per device)

The HTML game does not contain Firebase keys or passwords. Enter the public WebSocket address of your Node.js multiplayer backend. If this page is served by that backend, it normally detects the address automatically.

Use wss:// for an internet-hosted backend. Use ws://COMPUTER-LAN-IP:3000/ws only for local testing on the same trusted Wi-Fi network. Never put a Firebase service-account JSON or private key in this HTML file.

These rules restrict room reads/writes to the two anonymous-authenticated room members. A join code is a bearer invite—share it only with your friend. For a public production game, add tighter validation and abuse protection.
